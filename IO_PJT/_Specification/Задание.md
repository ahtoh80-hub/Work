1. Открывать файл excel с входными данными.
2. При открытии файла, открывается новое окно, где можно:
   - сопоставить базу данных IOclass (IOclass_new.md) с полями excel для чтения их в репозиторий iIOclass, выбирая каждую переменную класса IOclass. Что не сопоставлено с таблицей Excel, то не записывается в базу данных;
   - Можно выбрать начальную и последнюю строку считывания таблицы excel (по умолчанию с 1 и до последней строки, где есть текст);
   - отображается таблица открытого файла и цветом отображаются/подкрашиваются некорректные данные, если для данного столбца сопоставлена переменная IOclass (не соответствует типу данным переменной IOclass);
   - при выборе сопоставления переменных IOclass и столбца (маппинга) происходит проверка данных этого столбца на соответствию типа данных и корректность, чтобы данные корректно потом записать в эту переменную класса. В случае несоответствия записывать данный столбце в дополнительное поле (в IOclass 10 дополнительных столбцов для данных текстовых column1...column10). Графически это выглядит как выбор переменных в 2 столбцов и нажатие кнопки Bind;
   -  все некорректные данные не записываются в выбранные при сопоставлении поля БД IOclass, а в отдельном поле формируются сообщения об ошибке с указанием ключевого Tag. 
   -  Запись в репозиторий всего массива данных только после нажатия кнопки Apply.
   -  Иметь возможность сохранять выбранный маппинг полей и класса. Автоматически связывать поля в случае совпадения имен IOclass и имени столбца (Tag-Tag).
3. Отдельный функционал для анализа записанного репозитория и формирования генерации ошибок с указанием Tag и полей. Создать систему кодов ошибок.Все СОБЫТИЯ (Events) записываются в журнал сообщений (белым цветом нормальные события, желтым предупредительные и красным ошибки);
4. Репозиторий.
   - Иметь возможность отображать базу данных,сортировать, фильтровать, корректировать, добавлять, удалять и искать данные по всем полям/столбцам IOclass так и массовое копирования, удаление по строкам и столбцам;
   - возможность менять данные в таблице, копирование и вставка группами, строками и столбцами.
5. Функционал записи в access из репозитория данных класса IOclass:
   - создание одноименной таблицы со структурой IOclass в access (имя можно задавать);
   - Очистка таблицы access;
   - создание резервной копии таблицы с добавлением к имени даты события
   - запись в эту таблицу данных репозитория;
   - Считывание данных из выбранной таблицы access в репозиторий. Также использовать окно сопоставления данных таблицы access и переменных IOclass описанной ранее.
6. Код в C# должен быть сгруппирован по модулям (компонентный подход), папкам, использовать все основные возможности языка: Интерфейсы, СОБЫТИЯ, репозиторий, Сервисы, унаследование, ИНДЕКСАТОРЫ, ОПЕРАТОРЫ, ДЕЛЕГАТЫ, МЕТОДЫ, валидация и другие при необходимости.
7. Разработать графические окна в стиле скринов стилей графических окон:  Screen forma.JPG, Screen forma1.JPG, Screen всплывающее меню.JPG.
8. Все действия программы записываются в события и снизу ведется окно журнала с отображением всех событий (удачных и нет) и с фиксацией времени.
9. Реализовать на C#. В коде расписать подробные русскоязычные комментарии.
10. Пример данных в файле "пример данных"
