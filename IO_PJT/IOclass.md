# Полная структура класса IOPoint (Оптимизированная версия с дополнениями)

## 📋 Полная иерархическая структура

```
IOPoint - Точка ввода-вывода в системе автоматизации
│
├── Identification : Identification? - Идентификационные данные точки
│   ├── Code : int? - Порядковый номер строки в списке (из колонки "Код")
│   ├── Area : string? - Номер технологической установки/зоны (1-6 ЦИФР!)
│   ├── Title : string? - Номер установки/зоны (функциональное наименование)
│   ├── Loop : string? - Основной технологический контур Main (связывает точки одного процесса)
│   ├── SubLoop : string? - Вложенный субконтур (детализация внутри основного контура)
│   ├── ProcessLoop : string? - Технологический контур (технологическое разделение)
│   ├── Tag : string? - Уникальный тег устройства (главный идентификатор)
│   ├── ParsedTag : InstrumentTag? - Распарсенный тег (структурированные компоненты)
│   │   ├── Area : string? - Код площадки/завода (1-6 ЦИФР!)
│   │   ├── DeviceClass : string? - Класс прибора (1-5 букв A-Z)
│   │   ├── LoopNumber : string? - Номер технологического контура (1-5 цифр)
│   │   ├── TagNumber : string? - Порядковый номер прибора (1-3 ЦИФРЫ!)
│   │   ├── Suffix : string? - Суффикс (модификатор прибора, 0-3 символа)
│   │   ├── FullTag : string? - Исходный тег в полном виде
│   │   └── Separator : char? - Определенный разделитель компонентов (если отсутствовал - null)
│   ├── ProcessTag : string? - Технологический тег устройства (для технологических схем)
│   ├── System : SystemType? - Тип системы управления (DCS/SCS/GDS/)
│   ├── IoType : string? - Тип сигнала ввода-вывода (DO - дискретный выход, AI - аналоговый вход и т.п)
│   ├── Controller : string? - Имя контроллера (FCS, SCS, GDS) в системе управления
│   └── Location : LocationType? - Место установки оборудования (датчика, системы управления, подсистемы и т.п.)
│
├── Signal : Signal? - Технологические параметры сигнала
│   ├── Service : string? - Технологическое описание сигнала (на русском языке)
│   ├── ServiceEnglish : string? - Технологическое описание сигнала (на английском языке)
│   ├── InstrumentType : string? - Тип прибора/устройства (на русском языке)
│   ├── InstrumentTypeEnglish : string? - Тип прибора/устройства (на английском языке)
│   ├── Pid : string? - Номер P&ID (Piping and Instrumentation Diagram) для привязки к схеме
│   ├── SignalType : string? - Тип сигнала (I/O Type): DOR-P, DIR(I)-NAMUR, AIR-LP и др.
│   ├── ExProtection : ExProtectionType? - Взрывозащита оборудования
│   ├── Subsystem : string? - Идентификатор подсистемы (например, номер стойки или шкафа)
│   └── Auxiliary : string? - Вспомогательный прибор (сигнальный изолятор, преобразователь)
│
├── Ranges : Ranges? - Диапазоны измерений и уставки аварийной сигнализации
│   ├── Primary : Range? - Основной диапазон измерения (используется для масштабирования сигнала)
│   │   ├── Min : decimal? - Минимальное значение диапазона (по умолчанию 0)
│   │   ├── Max : decimal? - Максимальное значение диапазона (по умолчанию 100)
│   │   └── Unit : string? - Единица измерения (мм, kPa, ℃, %VOL, μS/cm, PH)
│   ├── Secondary : Range? - Вторичный диапазон измерения (для пересчета в другие единицы)
│   │   ├── Min : decimal? - Минимальное значение вторичного диапазона
│   │   ├── Max : decimal? - Максимальное значение вторичного диапазона
│   │   └── Unit : string? - Единица измерения вторичного диапазона
│   └── Alarms : AlarmSet? - Уставки аварийной сигнализации (для предупреждений и отключений)
│       ├── LL : AlarmLevel? - Авария "Нижний-Нижний" (критичный низкий уровень, остановка процесса)
│       │   ├── Value : decimal? - Значение уставки
│       │   └── Unit : string? - Единица измерения
│       ├── LL2 : AlarmLevel? - Второй "Нижний-Нижний" (дополнительный критичный уровень)
│       │   ├── Value : decimal? - Значение уставки
│       │   └── Unit : string? - Единица измерения
│       ├── L : AlarmLevel? - Предупреждение "Нижний" (внимание оператора, низкий уровень)
│       │   ├── Value : decimal? - Значение уставки
│       │   └── Unit : string? - Единица измерения
│       ├── H : AlarmLevel? - Предупреждение "Верхний" (внимание оператора, высокий уровень)
│       │   ├── Value : decimal? - Значение уставки
│       │   └── Unit : string? - Единица измерения
│       ├── HH : AlarmLevel? - Авария "Верхний-Верхний" (критичный высокий уровень, остановка процесса)
│       │   ├── Value : decimal? - Значение уставки
│       │   └── Unit : string? - Единица измерения
│       └── HH2 : AlarmLevel? - Второй "Верхний-Верхний" (дополнительный критичный уровень)
│           ├── Value : decimal? - Значение уставки
│           └── Unit : string? - Единица измерения
│
├── Cable : Cable? - Кабельное хозяйство (физическое подключение сигнала)
│   ├── Id : string? - Уникальный идентификатор кабеля (по проектной документации)
│   ├── Description : string? - Описание кабеля (назначение, куда подключен)
│   ├── Type : string? - Полный тип кабеля (количество и сечение жил, изоляция, оболочка)
│   ├── Designation : string? - Обозначение кабеля по проектной документации
│   ├── From : string? - Начальная точка кабеля (откуда идет)
│   ├── To : string? - Конечная точка кабеля (куда идет)
│   ├── Length : int? - Длина кабеля в метрах (целое число)
│   ├── Color : string? - Цвет кабеля или цвет изоляции жилы (BK - черный, BU - синий)
│   ├── Pair : int? - Номер пары или жилы внутри кабеля
│   ├── Note : string? - Дополнительное примечание по кабелю (изменения, особые условия)
│   ├── VendorDesignation : string? - Наименование кабеля по документации поставщика
│   ├── Drum : string? - Номер барабана для учета кабеля при монтаже
│   └── Voltage : string? - Напряжение питания для активных устройств (если применимо)
│
├── Equipment : Equipment? - Оборудование контроллера (привязка к аппаратным средствам)
│   ├── CableTecon : string? - Идентификатор кабеля по документации TECON (подрядчик)
│   ├── Mcc : string? - Номер подстанции MCC (Motor Control Center) для моторных сигналов
│   ├── ControlCabinet : string? - Идентификатор шкафа управления (Control Cabinet)
│   ├── MarshallingCabinet : string? - Идентификатор шкафа маршаллинга (Marshalling Cabinet)
│   ├── Cpu : string? - Тег процессора (CPU) в системе управления
│   ├── Chassis : Chassis? - Шасси (стойка) контроллера
│   │   ├── Main : string? - Идентификатор основного шасси (стойки)
│   │   └── Redundant : string? - Идентификатор резервного шасси (для горячего резервирования)
│   └── Module : Module? - Модуль ввода-вывода (I/O Module)
│       ├── Slot : string? - Номер слота основного модуля (например, A11, A13)
│       ├── SlotRedundant : string? - Номер слота резервного модуля (например, A12, A14)
│       ├── Channel : int? - Номер канала внутри модуля (например, 20, 21)
│       └── Type : string? - Тип модуля ввода-вывода (DI32, DO32P, AI16H и др.)
│
└── Revision : Revision? - Управление версиями и метаданными
    ├── Number : int? - Номер ревизии (версия данных)
    ├── Description : string? - Подробное описание изменений в текущей ревизии
    ├── Package : string? - Оборудование поставщика (пакетное оборудование, например "SDPump", "VINCI")
    ├── VendorField1 : string? - Дополнительное поле 1 (может содержать имя поставщика, например "Xinhui")
    ├── VendorField2 : string? - Дополнительное поле 2
    ├── Document : string? - Ссылка на техническую документацию (номер документа, статус)
    ├── AkerRevision : string? - Ревизия от Aker Solutions (если применимо)
    ├── FileName : string? - Имя файла-источника данных (откуда загружена информация)
    ├── Author : string? - Автор, создавший запись (ответственный за ввод данных)
    ├── DateEntered : DateTime? - Дата и время ввода информации в систему
    └── RowNumber : int? - Номер строки в документе-источнике (для обратного прослеживания)
```

## 📋 Детальное описание всех классов

### 1. IOPoint (Точка ввода-вывода)

Главный класс, объединяющий все аспекты точки ввода-вывода в системах автоматизации.

| Свойство | Тип | Описание | Обязательность |
|:---|:---|:---|:---|
| `Identification` | `Identification?` | Идентификационные данные точки (тег, контур, номер) | Нет |
| `Signal` | `Signal?` | Технологические параметры сигнала (тип прибора, взрывозащита) | Нет |
| `Ranges` | `Ranges?` | Диапазоны измерений и уставки аварийной сигнализации | Нет |
| `Cable` | `Cable?` | Данные о кабельном хозяйстве (кабель, цвет, длина, маршрут) | Нет |
| `Equipment` | `Equipment?` | Привязка к оборудованию контроллера (шкафы, стойки, модули, каналы) | Нет |
| `Revision` | `Revision?` | Информация о версиях и ревизиях документации | Нет |

---

### 2. Identification (Идентификационные данные)

Содержит все идентификаторы точки: теги, контуры, номера, описания.

| Свойство | Тип | Описание | Пример | Ограничения |
|:---|:---|:---|:---|:---|
| `Code` | `int?` | Порядковый номер строки в списке (из колонки "Код") | `45` | - |
| `Area` | `int?` | Номер технологической установки/зоны (географическое расположение) | `1400` | **1-6 ЦИФР!** |
| `Title` | `string?` | Номер установки/зоны (функциональное наименование) | `"1401"` | - |
| `MainLoop` | `string?` | Основной технологический контур (связывает точки одного процесса) | `"2701-XV-10101A"` | - |
| `SubLoop` | `string?` | Вложенный субконтур (детализация внутри основного контура) | `"2701-X-10105A"` | - |
| `ProcessLoop` | `string?` | Технологический контур (технологическое разделение) | `"2701-X-10101A"` | - |
| `Tag` | `string?` | Уникальный тег устройства (главный идентификатор) | `"2701-XZY-10101A"` | - |
| `ParsedTag` | `InstrumentTag?` | Распарсенный тег (структурированные компоненты) | См. InstrumentTag | - |
| `ProcessTag` | `string?` | Технологический тег устройства (для технологических схем) | `"2701-XZY-10101A"` | - |
| `System` | `SystemType?` | Тип системы управления (DCS/SCS/GDS) | `DCS` | - |
| `IoType` | `string?` | Тип сигнала ввода-вывода | `"DO"` | - |
| `Controller` | `string?` | Имя контроллера в системе управления | `"2000-S-SC-B01"` | - |
| `Location` | `LocationType?` | Место установки оборудования | `Field` | - |

### 3. InstrumentTag (Парсер тегов)

Парсер промышленных тегов с автоматическим разбором структуры.

| Свойство | Тип | Описание | Пример | Ограничения |
|:---|:---|:---|:---|:---|
| `Area` | `string?` | Код площадки/завода (технологическая установка) | `"2701"` | **1-6 ЦИФР!** |
| `DeviceClass` | `string?` | Класс прибора (тип устройства по функциональному назначению) | `"XZY"` | 1-5 букв A-Z |
| `Loop` | `string?` | Номер технологического контура (связывает приборы одного процесса) | `"10101"` | 1-5 цифр |
| `TagNumber` | `string?` | Порядковый номер прибора в контуре (уникальный идентификатор) | `"01"` | **1-3 ЦИФРЫ!** |
| `Suffix` | `string?` | Суффикс (модификатор прибора: резервный, основной, часть системы) | `"A"` | 0-3 символа |
| `FullTag` | `string?` | Исходный тег в полном виде (для обратного прослеживания) | `"2701-XZY-10101A"` | - |
| `Separator` | `char?` | Определенный разделитель (автоматически определяется при парсинге) | `'-'` | - |

**Примеры парсинга:**

| Тег | Area | DeviceClass | Loop | TagNumber | Suffix |
|:---|:---|:---|:---|:---|:---|
| `2701-XZY-10101A` | `"2701"` | `"XZY"` | `"10101"` | `"01"` | `"A"` |
| `123456-PDT-01001A` | `"123456"` | `"PDT"` | `"010"` | `"01"` | `"A"` |
| `42-FT-123` | `"42"` | `"FT"` | `"123"` | `"123"` | `""` |
| `P-9999` | `""` | `"P"` | `"9999"` | `""` | `""` |
| `123456PDT01001A` | `"123456"` | `"PDT"` | `"010"` | `"01"` | `"A"` |
| `TEMP-12345` | `""` | `"TEMP"` | `"12345"` | `""` | `""` |

### 4. Signal (Технологические параметры сигнала)

Детальная информация о сигнале: тип прибора, взрывозащита, тип сигнала.

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `Service` | `string?` | Технологическое описание сигнала (на русском языке) | `"Распределительный клапан для впуска стирола"` |
| `ServiceEnglish` | `string?` | Технологическое описание сигнала (на английском языке) | `"Styrene Inlet Switch Valve"` |
| `InstrumentType` | `string?` | Тип прибора/устройства (на русском языке) | `"Электромагнитный клапан"` |
| `InstrumentTypeEnglish` | `string?` | Тип прибора/устройства (на английском языке) | `"Solenoid valve"` |
| `Pid` | `string?` | Номер P&ID для привязки к схеме | `"2490156-1401-PR007-0101A"` |
| `SignalType` | `string?` | Тип сигнала (I/O Type): DOR-P, DIR(I)-NAMUR, AIR-LP и др. | `"DOR-P"` |
| `ExProtection` | `ExProtectionType?` | Взрывозащита оборудования | `ExD` |
| `Subsystem` | `string?` | Идентификатор подсистемы (например, номер стойки или шкафа) | `"RACK-01"` |
| `Auxiliary` | `string?` | Вспомогательный прибор (сигнальный изолятор, преобразователь) | `"Isolator-01"` |

### 5. Ranges (Диапазоны и уставки)

Диапазоны измерений и уставки аварийной сигнализации.

| Свойство | Тип | Описание |
|:---|:---|:---|
| `Primary` | `Range?` | Основной диапазон измерения (используется для масштабирования сигнала) |
| `Secondary` | `Range?` | Вторичный диапазон измерения (для пересчета в другие единицы) |
| `Alarms` | `AlarmSet?` | Уставки аварийной сигнализации (для предупреждений и отключений) |

#### 5.1. Range (Диапазон)

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `Min` | `decimal?` | Минимальное значение диапазона (по умолчанию 0) | `0` |
| `Max` | `decimal?` | Максимальное значение диапазона (по умолчанию 100) | `100` |
| `Unit` | `string?` | Единица измерения | `"%"` |

#### 5.2. AlarmSet (Уставки аварийной сигнализации)

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `LL` | `AlarmLevel?` | Авария "Нижний-Нижний" (критичный низкий уровень, остановка процесса) | `{ Value: 10, Unit: "%" }` |
| `LL2` | `AlarmLevel?` | Второй "Нижний-Нижний" (дополнительный критичный уровень) | `{ Value: 5, Unit: "%" }` |
| `L` | `AlarmLevel?` | Предупреждение "Нижний" (внимание оператора, низкий уровень) | `{ Value: 20, Unit: "%" }` |
| `H` | `AlarmLevel?` | Предупреждение "Верхний" (внимание оператора, высокий уровень) | `{ Value: 80, Unit: "%" }` |
| `HH` | `AlarmLevel?` | Авария "Верхний-Верхний" (критичный высокий уровень, остановка процесса) | `{ Value: 90, Unit: "%" }` |
| `HH2` | `AlarmLevel?` | Второй "Верхний-Верхний" (дополнительный критичный уровень) | `{ Value: 95, Unit: "%" }` |

#### 5.3. AlarmLevel (Уровень аварийной сигнализации)

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `Value` | `decimal?` | Значение уставки | `10` |
| `Unit` | `string?` | Единица измерения для данной уставки | `"%"` |

**Иерархия уровней:**
```
LL2 ← LL ← L ←─── НОРМА ───→ H → HH → HH2
(крит) (крит) (пред)          (пред) (крит) (крит)
```

### 6. Cable (Кабельное хозяйство)

Информация о физическом подключении сигнала.

| Свойство | Тип | Описание | Пример |
|:---|:---|:---|:---|
| `Id` | `string?` | Уникальный идентификатор кабеля (по проектной документации) | `"CBL-001"` |
| `Description` | `string?` | Описание кабеля (назначение, куда подключен) | `"Кабель к клапану 2701-XV-10101A"` |
| `Type` | `string?` | Полный тип кабеля (количество и сечение жил, изоляция, оболочка) | `"NH-KYJVP3 37x2.5mm2"` |
| `Designation` | `string?` | Обозначение кабеля по проектной документации | `"C-101"` |
| `From` | `string?` | Начальная точка кабеля (откуда идет) | `"2701-S-JB-D018"` |
| `To` | `string?` | Конечная точка кабеля (куда идет) | `"SIS"` |
| `Length` | `int?` | Длина кабеля в метрах (целое число) | `150` |
| `Color` | `string?` | Цвет кабеля или цвет изоляции жилы (BK - черный, BU - синий) | `"BK"` |
| `Pair` | `int?` | Номер пары или жилы внутри кабеля | `3` |
| `Note` | `string?` | Дополнительное примечание по кабелю (изменения, особые условия) | `"Прокладка по лотку L-01"` |

## ✅ Ключевые особенности структуры

1. **Все свойства nullable** — гибкость при работе с неполными данными
2. **Автоматический парсинг тегов** — через `InstrumentTag` (Area 1-6 цифр!)
3. **TagNumber — только цифры (1-3)** — строгое правило парсинга
4. **Двойные аварийные уровни** — `LL2` и `HH2` для дополнительной критической сигнализации
5. **Полная иерархия** — от общего `IOPoint` до детальных подклассов
6. **Поддержка DCS/SCS/GDS** — различные типы систем управления
7. **Метаданные источника** — `FileName`, `Author`, `DateEntered`, `RowNumber` для аудита
8. **Многоязычная поддержка** — описания на русском и английском языках
9. **Технологический тег** — `ProcessTag` для технологических схем
10. **Четкая иерархия Loop** — `MainLoop` → `SubLoop` → `ProcessLoop`
11. **Вторичные диапазоны** — поддержка пересчета в другие единицы измерения
