Функциональный блок MB_RTU_MASTER предназначен для обмена данными по протоколу Modbus RTU со Slave-устройствами. Блок формирует запросы чтения и записи данных на COM-порт процессорного модуля.

Функциональный блок MB_TCP_MASTER предназначен для обмена данными по протоколу Modbus TCP со server-устройствами. Блок формирует запросы чтения и записи данных на COM-порт процессорного модуля.  Блок MB_TCP_MASTER совместим только с ресурсами, которые имеют тип исполнения - Цикл реального времени.

ВНИМАНИЕ! Нельзя писать одновременно в один COM-порт больше чем с одного экземпряра MB_RTU_MASTER. Например, два блока MB_RTU_MASTER писать в один COM-порт одновременно не могут, а один блок в два COM-порта писать может.
 
Функциональный блок начинает выполняться по переднему фронту (при смене с FALSE на TRUE) входа Request. При этом происходит формирование Modbus запроса, на основе входных данных:
•SlaveId: адрес устройства Modbus Slave, подключенного к COM-порту;
•Mode: используемая Modbus функция для чтения или записи данных;
•Address: адрес первого бита/регистра считываемого с устройства или записываемого на устройство;
•Count: количество бита/регистров считываемых с устройства или записываемых на устройство.
После подачи команды выполнения (вход Request) выход Busy становится TRUE, означающий что выполняется передача Modbus-запроса и ожидание ответа от устройства. Максимально допустимое время ожидания полного ответа от устройства задается входом TimeOut в мс. После того как ответ получен или вышло время таймаута выход Busy сбрасывается, и взводится выход Done – признак завершенного запроса.
Когда ответ от устройства получен и нет ошибок данные из регистров передаются на выход DataOut в виде массива байт.
Для записи значений в Slave-устройство необходимо передавать массив байт на вход DataIn, при этом будут переданы команды записи всех регистров, заданные параметрами Address и Count.
Для преобразования значений из массива байт в форматы DINT и REAL можно воспользоваться функциями MB_TO_DINT и MB_TO_REAL соответственно. Для обратного преобразования из типов DINT и REAL в массив байт – функциями MB_FROM_DINT и MB_FROM_REAL.
В выхода ExecutionTime и AverageExecutionTime выводятся время выполнения последнего запроса и среднее время выполнения последних четырех команд.
Возможные ошибки при выполнении функционального блока MB_RTU_MASTER и MB_TCP_MASTER будут выводится на выходе Error.

Так как можно создавать только один экземпляр функционального блока MB_RTU_MASTER для COM-порт, то для формирования нескольких разных запросов необходимо поочерёдно подавать на входа блока (SlaveId, Mode, Address, Count) разные данные для формирования Modbus-запросов и массивы вычитанных и записываемых данных (DataIn и DataOut). Переключение между запросами можно выполнять по признаку завершения опроса (Done) и при необходимости формировать паузу между запросами.
